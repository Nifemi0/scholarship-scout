# Scholarship Scout Scope

## In scope for MVP

- One responsive web application.
- Curated scholarship catalog of approximately 30–50 records.
- Student profile for non-sensitive matching fields.
- Search, filtering, sorting, and no-result handling.
- Deterministic eligibility explanation.
- Scholarship details and source metadata.
- Comparison and human-approved shortlist.
- Personalized application checklist.
- Local browser persistence.
- Six documented WebMCP tools.
- Public deployment and open-source repository.

## Stretch scope

Only begin after the MVP journey is stable:

- Counselor view for multiple student profiles.
- Reminder export to calendar or downloadable checklist.
- Catalog administrator workflow for updating verification dates.
- Natural-language profile intake that maps into structured fields.
- Optional sign-in with privacy-preserving profile storage.
- More scholarship categories and regional catalogs.

## Explicitly out of scope

- Automatic application submission.
- Automatic email or message sending.
- Uploading or storing identity documents.
- Financial advice or admissions guarantees.
- Scraping the entire web during the hackathon.
- Claiming that a scholarship is verified when its source is unknown.
- General-purpose chatbot unrelated to scholarship actions.
- Complex recommendation models requiring opaque AI decisions.
- Paid subscriptions or payment processing.
- Native mobile applications.

## Scope decision rule

If a feature does not improve the path from **student profile → trustworthy match → approved shortlist → application checklist**, defer it until after the MVP.
